# Участие в разработке

## Окружение

```bash
nix develop            # единственное поддерживаемое окружение (flake.lock закреплён)
bash scripts/check.sh       # полный локальный гейт
```

Пин тулчейна: `rust-toolchain.toml` (1.95.0). Если `rustc --version` расходится с пином,
`bash scripts/check-rust.sh` падает — это не «шум», а рассинхронизация окружения.

## Что требуется для любого изменения

1. Ссылка на требование `DJP-*` и задачу backlog (A00…A13 / B / C / D).
2. Позитивные, отрицательные и граничные тесты; для DSP — offline reference.
3. `bash scripts/check.sh` зелёный. Ослаблять проверку, чтобы она прошла, запрещено.
4. Обновлённые `docs/requirements/traceability.csv` и затронутая документация. В полях этой
   таблицы **запятых быть не может** — разделитель один; перечисляйте через `;` или `·`. Гейт
   отвергает строку с 12 полями, но ловится это уже после правки, поэтому правило проще соблюдать.
5. Запись в `THIRD_PARTY.md` для каждой новой зависимости (до merge).
6. Свидетельства в `docs/qa/evidence/<task>/` — реальные команды и их вывод.

## Ветки и коммиты

- Ветка: `feat/A02-codec-prefetch`, `fix/…`, `docs/…`.
- Один коммит — одна задача; сообщение объясняет причину, а не пересказывает diff.
- Push и merge в `main` — за владельцем/интегратором; прямые изменения `main` запрещены.

## Код

- Edition 2024, `unsafe_code = deny` на уровне workspace: `unsafe` только точечно и с
  `// SAFETY:`-обоснованием.
- `unwrap`/`expect`/`panic` в библиотечном коде запрещены (`clippy::unwrap_used`), в тестах —
  разрешены.
- В audio callback нет аллокаций, блокировок, логирования, Qt, I/O и ML (DJP-NFR-001).
- Публичные интерфейсы и схемы меняются только через ADR (план §6.2).

## Лицензии

LICENSE — двойная `MIT OR Apache-2.0` (ADR-001 accepted). GPL-only код (Encdr, Ableton Link)
не включается никогда: он сделал бы комбинированную работу GPL. Код и ресурсы Traktor/NI/Mixxx не копируются (DJP-LIC-006).

## Аппаратура

Тест с S4 MK3 без физического устройства помечается `hardware-not-verified`; заявлять `passed`
запрещено. Моторизованные джоги — только после ADR-007.
