# Документация DJ Platform

Проект на этапе M0: управляющие документы уже есть, реализация начинается с A00.
Ниже — где что лежит и что считается источником истины.

## Иерархия документов

| Документ | Роль | Статус |
|---|---|---|
| `../DJ_Platform_TZ_v0.1_RU.md` | Источник требований `DJP-*` | утверждён владельцем (v0.1) |
| `../DJ_Platform_Implementation_Plan_v0.1_RU.md` | Порядок разработки, gate и роли | утверждён владельцем (v0.1) |
| `../DJ_Platform_Initial_Backlog_v0.1.yaml` | Задачи A00–A13 | принят |
| `requirements/traceability.csv` | Требование → реализация → тест → свидетельство | создан, 136 требований, статусы `unverified` |
| `adr/*.md` | Решения: лицензия (accepted), аудиобэкенд (измеряем), UI-мост (accepted: отдельный процесс) | 0001/0003 accepted, 0002 измеряется в A05 |
| `architecture/*.md` | Карта крейтов, RT-контракт, обзор | карта и RT-контракт созданы |
| `qa/*.md`, `qa/evidence/<task>/` | Методика, стенд, фактические доказательства | стенд зафиксирован, evidence для A00 |
| `agents/AGENTS.md` | Правила работы ИИ-агентов в этом репозитории | создан |
| `parity/*` | Инвентарь эталона и матрица паритета | пустой каркас, заполняется после ADR-004 |
| `hardware/s4mk3/*` | Профиль и матрица проверок S4 MK3 | пусто, A09 |

При расхождении ТЗ и плана приоритет у ТЗ; расхождение оформляется ADR/issue, а не молчаливым
изменением кода.
