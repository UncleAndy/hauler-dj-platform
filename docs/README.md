## Что ещё не создано намеренно

- `schemas/*-v1.json` — JSON Schema файлов нет: контракты `command-v1`/`state-v1` зафиксированы
  типами `dj-domain` и побайтовыми golden-тестами (`crates/dj-domain/tests/wire_format.rs`), что
  ловит дрейф формата строже, чем схема, лежащая рядом с кодом. Отдельные `.json` схемы нужны,
  когда появится клиент не на Rust (мост A06) — тогда они генерируются из этих же типов.
- `crates/dj-fx`, `dj-time-stretch`, `dj-sync`, `dj-stems`, `dj-remix`, `dj-pattern`,
  `dj-controller-s4mk3`, `dj-recording`, `services/stem-worker` — создаются вместе со своими
  задачами; сейчас перечислены в `architecture/crate-map.md` как planned.
- `docs/hardware/s4mk3/*` — заполняется по фактам подключения устройства, не по предположениям.
