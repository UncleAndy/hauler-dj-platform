# Инвентарь эталона

Заполняется в M0 (план §3, п.8) и фиксируется ADR-004 — до закрытия R0.

## Обязательные поля

- точная версия Traktor Pro 4 (и дата фиксации);
- источники сведений: официальная документация, справочные таблицы функций, публичные описания;
- перечень сценариев, которые сравниваются (playback, cue/loop, sync, browser, FX);
- список функций, которые **запрещено** копировать буквально: закрытые алгоритмы, фирменная
  графика, иконки, сэмплы, названия proprietary-эффектов, прошивки.
