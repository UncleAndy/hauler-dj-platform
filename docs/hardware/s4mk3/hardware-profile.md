# S4 MK3 — профиль устройства (A09)

Что за устройство мы поддерживаем, чем оно является для программы и что в нём ещё не измерено. Профиль
описывает **возможности**, а не протокол: байты живут в `protocol-notes.md`.

## Кто это

| Поле | Значение | Происхождение |
|---|---|---|
| Модель | Native Instruments Traktor Kontrol S4 MK3 | public-source |
| USB | `0x17cc` / `0x1720` | public-source |
| Что даёт программе | аудиоинтерфейс (4 выхода / 8 входов) + HID-контроллер + два дисплея | observed + public-source |

## Аудио (измерено, A05)

| Факт | Значение |
|---|---|
| Выходы | 4 канала (`FL FR FC LFE`), 8 каналов захвата, 44,1 / 48 / 88,2 / 96 кГц, S32_LE 24 бит |
| Шины | 0–1 master, 2–3 cue — проверено тоном и прослушиванием |
| Громкости master / booth / наушников и mix наушников | регулирует сам интерфейс, программа их не видит |

## Органы

| Группа | Состав | Происхождение |
|---|---|---|
| Деки | 4 (A–D), у каждой: play, cue, sync, shift, 8 падов с режимами, энкодер, темпофейдер, джог с мотором и касанием | public-source |
| Микшер | 4 канальных полосы: фейдер, три ручки EQ, фильтр, cue, регулятор громкости канала | public-source |
| Эффекты | два блока по три ручки, mix, main, три кнопки выбора | public-source |
| Браузер | энкодер прокрутки, кнопки загрузки дек | public-source |
| Дисплеи | два, 320×240, RGB565, по одному на пару дек | public-source |

## Чего в профиле ещё нет

1. Точные смещения органов — снимаются на устройстве (A09), таблица в `protocol-notes.md` пуста не
   случайно.
2. Калибровка центров темпофейдеров по декам — измеряется, хранится в профиле.
3. Яркость LED (младшие биты значения цвета) — гипотеза.
4. Поведение при отключении кабеля посреди воспроизведения — не проверялось.
5. Что показывать на экранах — решения нет; до него кадры не отправляются.

## Ограничения, которые профиль задаёт программе

- Устройство можно использовать только как аудиоинтерфейс, без управления: это законный режим, и он
  должен работать, даже если HID-коллекция не найдена.
- Моторы — за флагом и после ADR о безопасности; без флага джог ведёт себя как обычный.
- Дисплеи на Windows требуют WinUSB для интерфейса 4: если пользователь не поставил драйвер, программа
  обязана сказать это словами, а не молча ничего не показывать.
