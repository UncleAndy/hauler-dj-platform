# S4 MK3 — заметки о протоколе (только факты)

Артефакт прохода **чтения** в clean-room-процедуре (ADR-0006, п. 9). Здесь нет кода: только факты о
протоколе с указанием происхождения. Драйвер пишется по этому документу и **не** обращается к
GPL-источникам.

Легенда происхождения:

- `observed` — снято с устройства нашими средствами, воспроизводимо;
- `public-source` — взято из публичного описания/маппинга как указатель; требует проверки на железе;
- `assumed` — гипотеза, в код не попадает до проверки.

## Идентификация

| Факт | Значение | Происхождение | Проверено на устройстве |
|---|---|---|---|
| Транспорт | HID, не MIDI | public-source | нет |
| Vendor / Product | `0x17cc` / `0x1720` | public-source | нет |
| Коллекция с протоколом | vendor-defined, `usage_page 0xff01`, `usage 0x0`, `interface 3` | public-source | нет |
| Аудио | 4 playback, 8 capture, 44,1–96 кГц, S32_LE 24 бит | observed (A05) | да |
| Шины на аналоговых выходах | 0–1 master, 2–3 cue | observed (тон + прослушивание) | да |

## Что известно о возможностях (без деталей протокола)

| Возможность | Статус | Комментарий |
|---|---|---|
| Два дисплея | есть | разрешение, кодировка и размер пакета **неизвестны** — измеряются в A09 |
| Моторизованный джог | есть | сила задаётся параметром; включать только после ADR о безопасности моторов |
| LED / RGB-подсветка | есть | какие группы адресуемы — неизвестно |
| Сенсор джога (touch) | предположительно | `assumed` |

## Как снимаем

1. Наш пробник (A09) открывает `/dev/hidraw*` для нужной коллекции и пишет сырые репорты в файл-фикстуру.
2. Одно действие — один прогон, с отметкой «что нажали»; фикстура коммитится в `tests/fixtures/`.
3. Каждая строка таблицы выше получает `observed` только после того, как байт воспроизведён дважды.
4. Исходящие пакеты на этом этапе не отправляются вообще (read-only).

Сторонние утилиты захвата допустимы как отдельные программы, но в сборку не входят и в дерево не
копируются.
