# S4 MK3 — журнал clean-room

Зачем: доказать, что драйвер написан по фактам, а не переведён из GPL-кода (ADR-0006, п. 9;
DJP-LIC-003/006). Запись делается в момент чтения, а не задним числом.

## Правила

1. Проход **чтения** и проход **реализации** — разные задачи и разные сессии.
2. В задаче реализации источники из таблицы ниже не открываются. Вход — только
   `protocol-notes.md`.
3. В репозиторий не попадают ни фрагменты кода, ни файлы маппингов, ни их «перевод» на Rust.
4. Каждый факт, попавший в notes, помечается происхождением; `assumed` не реализуется.

## Записи

### 2026-11-05 — проход чтения (исследование, не реализация)

- **Что смотрели:** `mixxxdj/mixxx` — файл `LICENSE` и `res/controllers/Traktor Kontrol S4 MK3.hid.xml`.
- **Зачем:** понять, существует ли публичное описание протокола и где искать вендорскую коллекцию.
- **Извлечённые факты (перенесены в `protocol-notes.md` как `public-source`):**
  - транспорт — HID, не MIDI; маппинг состоит из XML-описания устройства и JS-скрипта;
  - `vendor_id 0x17cc`, `product_id 0x1720`, `usage_page 0xff01`, `usage 0x0`, `interface 3`;
  - у устройства есть два дисплея и моторизованный джог с настраиваемой силой.
- **Что НЕ извлекалось:** структура скрипта, имена функций, таблицы репортов, константы кодирования
  экрана, фрагменты XML. Код не копировался и не переводился.
- **Лицензия источника:** GPL-2.0-or-later (`LICENSE` Mixxx). Использование — только как указатель
  на факты, в соответствии с DJP-LIC-003/006. Строка в `THIRD_PARTY.md` добавлена.
- **Следующий шаг:** A09 — снять карту органов и дисплеев на устройстве (read-only) и заменить
  `public-source` на `observed`. Задача реализации драйвера эти файлы не открывает.
