Чтобы установка работала в 100% случаев — независимо от того, подключен S4 MK3 в момент установки или нет — нужно использовать предварительно сгенерированный пакет драйвера (WinUSB) + утилиту pnputil.exe.
В отличие от Zadig и wdi-simple, которые ищут живое устройство на шине USB, pnputil.exe загружает драйвер напрямую в системное хранилище (DriverStore) и привязывает его к аппаратному ID (USB\VID_17CC&PID_1720&MI_03). Как только пользователь подключит контроллер (сегодня или через месяц), Windows автоматически применит этот драйвер.
Вот пошаговая схема, как это реализовать:

Шаг 1. Подготовьте пакет драйвера один раз (на вашем ПК)

Вы можете собрать готовый пакет без подключения контроллера с помощью консольной утилиты wdi-simple.exe (входит в релизы libwdi):
cmd
wdi-simple.exe -n "Traktor S4 MK3 Display" -v 0x17cc -p 0x1720 -i 3 -t 0 -d "s4_mk3_driver" -e
Используйте код с осторожностью.
• -v 0x17cc -p 0x1720 -i 3 — указывает строго на интерфейс экранов S4 MK3 (Interface 3).
• -t 0 — выбирает драйвер WinUSB.
• -e (--extract) — не устанавливает драйвер, а просто сохраняет готовые файлы в папку s4_mk3_driver.
Внутри папки s4_mk3_driver появятся:
• Traktor_S4_MK3_Display.inf
• Traktor_S4_MK3_Display.cat (подписанный файл каталога)
• папки amd64 / x86 с библиотеками WinUSB.
(Совет: чтобы в будущем избежать проблем с сертификатами на машинах пользователей, извлеките открытый ключ сертификата из .cat файла в driver.cer через свойства файла в Windows -> «Цифровые подписи» -> «Просмотр сертификата» -> «Копировать в файл», либо переподпишите .cat своим сертификатом).

Шаг 2. Добавьте установку в ваш инсталлятор

Включите папку s4_mk3_driver (вместе с driver.cer) в дистрибутив. Во время установки (когда инсталлятор уже получил права администратора) выполните две системные команды в тихом режиме:
1. Добавление сертификата в доверенные (чтобы Windows не блокировала установку .inf пакета при подключении пульта):cmd
certutil.exe -addstore -f "Root" "{app}\driver\driver.cer"
certutil.exe -addstore -f "TrustedPublisher" "{app}\driver\driver.cer"
Используйте код с осторожностью.
2. Предзагрузка драйвера в систему (DriverStore):cmd
pnputil.exe /add-driver "{app}\driver\Traktor_S4_MK3_Display.inf" /install
Используйте код с осторожностью.

Как это сработает на компьютере пользователя:

• Если S4 MK3 не подключен при установке: pnputil запишет драйвер в хранилище и вернет код 0 (успех). При первом же подключении контроллера Windows без единого вопроса назначит WinUSB на Interface 3.
• Если S4 MK3 уже подключен при установке (и на нем стоит родной драйвер NI): флаг /install в pnputil заставит Windows принудительно обновить драйвер на подключенном устройстве прямо во время работы инсталлятора (так как у свежего .inf файла дата/версия обычно новее, чем у драйвера NI 2018–2020 годов; при необходимости дату в строке DriverVer внутри .inf можно выставить на текущую перед подписью).
