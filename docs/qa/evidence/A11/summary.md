# A11 — эталонные файлы, прослеживаемость и контракты агентов

**Статус:** закрыто. Критерии бэклога выполнены: гейт падает при неожиданном изменении эталонного
файла, и каждая строка traceability либо имеет владельца и проверку, либо честно помечена как
непроверенная.

## Что сделано

**Эталонные аудиофайлы.** Шесть файлов в `crates/dj-codec/tests/fixtures/audio/` закреплены
манифестом `audio.sha256` (формат `sha256sum`). `scripts/check-fixtures.sh` в гейте проверяет три
вещи: хэши совпадают, ни один файл из манифеста не пропал, ни один файл в каталоге не появился
без строки в манифесте. В сообщении об ошибке — готовая команда пересборки манифеста, чтобы
изменение было осознанным, а не «перезаписал, чтобы прошло».

**Прослеживаемость.** `scripts/check-docs.sh` теперь проверяет не только наличие строки и 11 полей,
но и смысл: статус из четырёх допустимых (`passing`/`review`/`unverified`/`planned`); `passing`
обязан называть тест или команду; `passing` и `review` обязаны ссылаться на существующий файл
свидетельств.

**Контракты агентов.** `docs/agents/AGENTS.md` дополнен двумя правилами: эталонные файлы не
перезаписываются ради прохождения теста, а строка traceability — обещание, которое проверяет гейт.

## Проверка, что гейты действительно кусаются

```
$ printf 'x' >> .../tone-1s-44100.flac && bash scripts/check-fixtures.sh
fixtures: a golden file changed or is missing:
  crates/dj-codec/tests/fixtures/audio/tone-1s-44100.flac: FAILED
exit=1
$ touch .../audio/extra.wav && bash scripts/check-fixtures.sh
fixtures: these files are not in the manifest: extra.wav
exit=1
$ (DJP-MIX-005 помечен passing без теста) bash scripts/check-docs.sh
traceability: DJP-MIX-005 is passing but names no test or command
$ (DJP-MIX-005 помечен review со ссылкой на несуществующий файл)
traceability: DJP-MIX-005 points at evidence that does not exist: docs/qa/evidence/NOPE/summary.md
```

После каждой проверки файлы восстановлены; гейт снова зелёный.

## Ограничения

- Манифест покрывает только каталог аудио-фикстур кодека. Другие двоичные артефакты (например,
  записанные HID-отчёты S4) получат свои манифесты вместе с A09.
- `check-fixtures.sh` не проверяет *содержание* файлов (тон, тишину, каналы) — это делают тесты
  кодека; здесь речь только о неизменности байтов.
