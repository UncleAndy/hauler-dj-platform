# B08 · Коллекция в браузере

Раздел `Collection` рельса: список коллекции из корня, темп и тональность из `.djmeta`, поиск по
имени, загрузка в деку. Проверяется `--browser-check` — он входит в `scripts/ui.sh --smoke`.

## Что проверено

| Проверка | Результат |
|---|---|
| раздел перечисляет корень | `collection /tmp/… -> 2 tracks in mode collection` |
| имя строки — имя файла от импорта | `ANH - tonight`, `Bbno$ - ADD` |
| порядок по имени | `ANH` раньше `Bbno$` |
| темп и тональность из `.djmeta` | `bpm 128`, `key 8m` у трека с записью; у второго — ничего |
| поиск | `1 of 2` по «bbno», обратно `2` |
| загрузка из коллекции | `loaded /tmp/…/A/N/ANH - tonight.flac into C`, раздел остался коллекцией |
| нажатие на строку рельса | `sections -> collection (2 tracks), then files` |
| корень переживает перезапуск | свежий `LayoutSettings` читает `collection_root` из файла |

Дерево в проверке настоящее: два каталога, два файла и `.djmeta` с темпом и тональностью у одного из
них. Путь в ответе панели сравнивается с путём выбранной строки, а не просто с началом строки.

## Что нашлось по дороге

`loadInto` читал `browser.selected` дважды: `Bridge.load` двигает папку браузера, и второе чтение
попадало уже в другую строку — панель сообщала путь, которого не отправляла. Загрузка теперь читает
выбор один раз.

Загрузка из коллекции выбрасывала список в папку трека: обработчик загрузки звал `browser.open`.
Теперь папка запоминается отдельно (`rememberFolder`), а вид меняет только `Files`.

## Чего нет

- индекса: список строится обходом корня при входе в раздел (777 файлов — доли секунды, 100 000 —
  уже нет); `AC-MEDIA` ждёт SQLite из `MEDIA-007`;
- колонок и сортировки по темпу и тональности, плейлистов;
- drag-and-drop (`MEDIA-008`).
