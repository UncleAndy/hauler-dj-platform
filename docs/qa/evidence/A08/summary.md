# A08 — переносимые метаданные трека и индекс над ними

**Статус:** реализовано, ожидает ревью владельца. Требование `DJP-DATA-006` заведено в этой же
задаче: метаданные едут вместе с музыкой, база — пересобираемый индекс.

## Что сделано

`crates/dj-library` из заглушки стал четырьмя модулями:

| Модуль | Что делает |
|---|---|
| `meta` | Типы записи: fingerprint, cue в кадрах, beatgrid с якорями, петли, gain, key, рейтинг, заметки, `analysis_lock`, `revision`/`updated_at_ms`; неизвестные поля сохраняются при перезаписи |
| `fingerprint` | Размер + FNV-1a по первым и последним 64 КиБ: переименование видно, чтение всей библиотеки не нужно |
| `sidecar` | `.djmeta/<имя файла>.json`; атомарная запись (временный файл + `rename`); битый файл не трогается |
| `store` | Две копии (рядом с музыкой и зеркало), выбор победителя по `revision`→`updated_at_ms`, конфликт отдаётся наружу, `adopt` переносит запись на новое имя файла |
| `index` | SQLite (rusqlite, bundled): только поля поиска и сортировки, WAL, `user_version`, `rebuild`/`upsert`/`search`/`by_fingerprint` |

Схема файла — `schemas/djmeta-v1.json` (создана).

## Критерии приёмки

| Критерий бэклога | Чем закрыт |
|---|---|
| Cue, сетка и петля едут с музыкой | `cue_points_travel_with_a_copied_folder`: папка скопирована, метаданные прочитаны в другом «доме» |
| Удаление базы и рескан всё возвращает | `deleting_the_index_restores_it_by_scanning`: файл БД удалён, `Index::open` создал пустую, скан вернул 2 строки |
| Read-only носитель работает через зеркало | `a_read_only_folder_falls_back_to_the_mirror` (каталог `0o555`) |
| Переименование не плодит дубль | `a_renamed_file_keeps_its_metadata` + `Store::adopt`, ключ строки — fingerprint |
| Битые метаданные не ломают трек | `a_broken_sidecar_is_reported_and_the_mirror_still_answers`: оригинал байт-в-байт на месте, отвечает зеркало |
| Расхождение копий не затирается молча | `a_disagreement_is_reported_rather_than_swallowed`: побеждает `revision`, проигравший возвращается; при равных ревизиях и времени отдаются обе версии |
| В базе нет cue-точек | `the_index_carries_no_cue_points`: колонок `cue`/`grid`/`loop` нет |

## Ограничения (не проверено)

- `dj-session` (настройки, сессии, автозагрузка) остаётся заглушкой: `DJP-SET-002/003` не закрыты,
  это следующая часть A08.
- Миграция индекса с предыдущей схемы не проверялась: схема первая, `PRAGMA user_version = 1`.
- Запись в теги файла (ID3 GEOB, Vorbis `DJP_META`, MP4 freeform) не реализована — по требованию
  это отдельная команда, и её место в B08.
- Волновая форма в метаданные не входит намеренно (производное по `DJP-DATA-003`); кэш живёт
  отдельно и пересобирается.
