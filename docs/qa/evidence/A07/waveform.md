# Волновые формы: конверт и кэш (A07, часть 1)

`crates/dj-analysis` больше не заглушка: конверт (min/max на столбец), кэш на диске с отпечатком
файла, ссылка на конверт в состоянии деки.

## Время — в кадрах источника

Столбец `n` покрывает кадры `[n * frames_per_bucket, (n + 1) * frames_per_bucket)`. Поэтому
плейхед ставится по `frame / frames_per_bucket` без масштабных поправок — это и есть требование
DJP-MEDIA-003. Тест `the_timebase_maps_a_playhead_to_the_right_column` держит границу: кадр 511 —
столбец 0, кадр 512 — уже первый.

## Кэш и его отпечаток

Отпечаток = размер файла + время изменения в наносекундах. Дёшево читается и меняется при любом
перекодировании, ретегировании или замене файла — то есть ровно тогда, когда старый конверт
описывает другой звук. Формат файла: `DJWAVE01`, отпечаток, частота, размер столбца, число столбцов,
затем пары `min/max` в i16 (точность 1/32767 — для картинки избыточна).

Кэш лежит в `$XDG_CACHE_HOME/hauler-dj/peaks`, никогда в коллекции. Имя файла включает разрешение:
грубый конверт не может быть выдан там, где попросили тонкий.

## Проверено

7 тестов на реальных фикстурах (`tone-1s-44100.flac`, `silence-then-tone-2s-44100.flac`):

| Тест | Что держит |
|---|---|
| `the_envelope_describes_the_file_at_a_fixed_timebase` | 1 с при 44,1 кГц — 86–87 столбцов по 512 кадров, ровный конверт у тона |
| `the_timebase_maps_a_playhead_to_the_right_column` | граница 511/512, за концом — последний столбец |
| `silence_is_flat_and_a_tone_is_not` | тишина < 0,01, тон > 0,3 в нужных местах файла |
| `the_cache_returns_what_it_stored` | второй вызов не декодирует, данные совпадают в пределах шага i16 |
| `a_changed_fingerprint_invalidates_the_cache` | заменённый файл не получает старый конверт |
| `a_different_resolution_never_reuses_another_ones_entry` | 128 и 512 — разные продукты |
| `an_empty_envelope_is_harmless` | пустой конверт не паникует |

Живой прогон через протокол (10 с файла 48 кГц, 960 000 кадров):

```
waveform: {'path': '.../wave-track-c140af7e116af553-512.wave', 'frames_per_bucket': 512,
           'buckets': 1875, 'sample_rate': 48000}
file exists: True size: 7556     # 56 байт заголовка + 1875 * 4
```

1875 = 960 000 / 512 — ровно, без потерь на хвосте.

## Что осталось в A07

- Отрисовка в QML: сейчас состояние сообщает, **где** конверт, но панель деки его не рисует.
- Зум: грубый и тонкий конверты уже независимы в кэше, но UI просит только обзорный.
- Фоновая подготовка: анализ идёт в потоке загрузчика, то есть блокирует следующую загрузку до
  окончания; отдельная очередь для библиотеки — это A08.
