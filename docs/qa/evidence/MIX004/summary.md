# MIX-004 — законы кроссфейдера: cut-in и hamster

- **Требование:** DJP-MIX-004 (presets кривой и назначение каналов A/B/Off; при расширении C/D тоже)
- **Дата:** 2026-11-17
- **Артефакты:** `crates/dj-mixer/tests/crossfader_laws.rs`, `crates/dj-mixer/tests/crossfader_click.rs`, `crates/dj-domain/tests/crossfader_wire.rs`, `--curve-check` в гейте

## Что добавлено к прежним четырём законам

| Что | Как проверено | Результат |
|---|---|---|
| Пятый закон `Cut { cut_in }`: до cut сторона закрыта, дальше рампа по децибелам от −60 до 0 за два процента хода | `a_cut_curve_opens_at_the_cut_in_point`: при `cut_in = 5 %` на 4 % хода −60 дБ, на 6 % — 0 дБ, дальше остаётся открытым, вторая сторона зеркальна | ✅ |
| Номер cut — величина, а не константа | `the_cut_in_is_the_number_the_dj_asks_for`: при 7 % тот же ход ещё закрыт, разница с 5 % больше 20 дБ | ✅ |
| Hamster переворачивает фейдер | `the_hamster_switches_the_sides`: та же ручка открывает другую сторону, выключение возвращает как было | ✅ |
| Закон ездит по проводу со своим числом | `a_cut_law_travels_with_its_number` (`{"cut":{"cut_in":7}}`), `the_old_laws_keep_their_names` — старые законы побайтово прежние | ✅ |
| Фейдер не щёлкает при ходе | `the_gate_does_not_click`: шаг в один отсчёт не больше 0,03 пика; при откате рампы читается 0,4955 против пика 0,5 | ✅ |
| Контроль: неподвижный фейдер ступеньки не даёт | `a_still_fader_makes_no_step_at_the_block_boundary` | ✅ |
| Рампа не съедает точность закона | `a_settled_fader_is_exactly_where_the_law_says`: установившийся фейдер на половине хода даёт пик 0,25 | ✅ |
| Интерфейс: кнопка cut, поле cut-in, подсветка по снапшоту | `--curve-check`: «cut-in 5 -> engine says 5, button lit, field says 5 %», затем 7 | ✅ |
| Hamster в протоколе и снапшоте | `DjCommand::SetHamster`, `Snapshot.hamster`; golden-форма провода не изменилась (поле пропускается, пока false) | ✅ в протоколе |
| Hamster в интерфейсе | **не сделано:** кнопка не влезла в вертикальный бюджет микшера (`--eq-check`: «knobs end at 265 px, meter A starts at 238 px»), место ждёт решения владельца | ⏳ |

## Числа, по которым принято

Hansen: ход кроссфейдера 45 мм, cut-in 2–3 мм → 4,4–6,7 % хода. По умолчанию 5 %
(`DEFAULT_CUT_IN_PERCENT`), фронт — два процента хода в децибелах: амплитудная рампа почти весь
ход молчит и приходит вся сразу.

## Гейты

`gate88` (закон), `gate90`–`gate91` (рампа и три блока в тесте движка), `gate93`–`gate97`
(интерфейс и проверка), `gate98` (видимость кнопки размера).

## Известное

- Вход в штрейчер щёлкает сам по себе (0,4542 против 0,0151 без keylock) — к кроссфейдеру отношения
  не имеет, записано в `docs/architecture/scratch.md`.
- Кнопка hamster: протокол готов, места в раскладке нет.
