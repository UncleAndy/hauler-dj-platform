# Карта подсветки S4 MK3: байт отчёта 128 → что загорается.
#
# Снято владельцем на своём контроллере перебором `dj-controller --lights-map`: по одному байту, ответ набран руками
# в терминале. Это наблюдение, а не выписка из чужого кода: у каждого байта есть человек, который видел, что
# загорелось.
#
# Байт задаёт ЦВЕТ, а не только «включено»: на байте 8 коды 4, 8, 12 и 16 дали разные цвета (ответ владельца, 23.11).
# Значит панель умеет цвет; яркость придётся искать отдельно.
#
# Опечатки исправлены при переносе: имя описывает железо, а не мнение снимавшего, и поиск по имени не должен зависеть
# от того, попала ли буква. Что исправлено: `Rigth` → `Right`, `Lefr` → `Left`, `lft` → `left`, `selec` → `select`,
# `hedphones` → `headphones`, и `Deck A FX on` → `Deck A FX on button` (у соседних дек кнопка названа так же).
#
