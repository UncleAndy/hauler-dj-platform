# benchmarks

Скрипты и результаты замеров RT: callback time avg/p99/max, xruns, underruns, round-trip latency.

Правила: результат без конфигурации стенда (`docs/qa/reference-rig.md`) не принимается;
сравнение графиков между разными конфигурациями запрещено.

Появится вместе с A01/A05 (headless bench + device probe).
